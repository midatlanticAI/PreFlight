## The rules this push earned

These are the ones worth carrying forward. Most were paid for twice.

- **A masking bug is bidirectional, and the invisible half is the dangerous
  one.** Leaked comments make noise somebody can see. Swallowed code makes a
  clean report. Measure both directions, always.
- **An unterminated construct is evidence of a mis-lex, not of a giant
  comment.** `src/data/*` in JSX copy opened a block comment nothing closed and
  blanked 95 of 187 lines of our own `TermsView.jsx`. Prefer under-masking.
- **Grammar beats vocabulary.** "Does this contain a code keyword" fires on
  English constantly, because `if`, `for`, `return` and `class` are ordinary
  words.
- **A guard that suppresses findings is a security control.** The prose guard
  asked whether a line _contained_ prose while callers used it to skip the
  whole line, so one readable sibling property silenced criticals. Shipped and
  fixed the same day.
- **Never test one probe in isolation and report it as the product.** The claim
  "the SSRF probe misses everything" was wrong and reached a commit message
  before being corrected. Run the probe set the app runs.
- **Zero is only meaningful if the probe looked.** Report the sites reached,
  not just the findings emitted.
- **A corpus with none of what you hunt is not evidence.** The unkeyed AWS
  pattern was dropped for this reason.
- **Controls are not scaffolding.** Twenty-six harvested advisory pairs proved
  nothing; five synthetic controls caught a live gap in shipped code.
- **The lesson has to reach the template.** The TLS adapter reported itself
  seven times, hours after the masking work, because the rule lived in a commit
  message and not in the code a new probe starts from.

Both remaining security findings on our own tree are content we ship on

### 5. The 1000-repo sweep, rescoped

**The fix-PR corpus does not measure recall, and that was my claim to make and
to withdraw.** Measured honestly: 26 pairs, minus 3 mislabelled, minus 16 not
statically decidable, leaves 7 fair-game pairs and 0/7 detected. The denominator
is the wrong population — advisory-linked fixes are library-maintainer work
(one fix was in the Svelte compiler, another monkeypatched a third-party
package), and PreFlight audits application code.

What it CAN do is measure precision: 38 files a human certified as fixed
produced zero findings in the patched regions.

So the sweep still needs human adjudication, and the plan stands: sample by
language and stars, scan, cluster by probe and shape, surface one exemplar per
cluster for a call, feed verdicts back as fixtures.

Two verified facts to keep, both non-obvious and both expensive to rediscover:

- **Union OSV records by `aliases` before filtering.** PYSEC carries the commit;
  GHSA carries the CWE. Neither carries both. Missing this makes the harvestable
  pool look about ten times smaller than it is.
- **Zero GitHub API calls are needed.**
  `raw.githubusercontent.com/{owner}/{repo}/{sha}^/{path}` resolves the true
  parent blob, so the 60/hour unauthenticated budget is never touched.

Harvester and corpus are in the session scratchpad, not the repo.

## Process that earned its place

**Contextless adversarial agents.** Six ran this push. They found three
same-day regressions our own suites could not, and they corrected four of my
premises: the SSRF gap did not exist, the reversed-operand password compare
already worked, the AWS secret pattern already existed, and the `exec` two-step
already fired. Self-authored tests share the author's blind spots. This is the
only check that has caught that class.

Give them the house rules explicitly — comment-blind matching, precision
measured on both canaries, every new finding justified by quoting the code —
and invite a **no**. Two of the six declined to ship something, with evidence,
and both were right.

**Verify before integrating.** Every agent result was reproduced locally before
any of it landed. Two reports were partly wrong in ways that would have shipped.
