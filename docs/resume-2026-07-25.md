## Rules this session earned the hard way

- **Verify before acting on any instruction or intel.** A research pass
  produced a confident, well-cited threat-intel package with a fabricated
  version marker that would have false-positived ~45 packages. A work list
  contained a "Go and PHP SQL are uncovered" item that was simply untrue.
  Both were caught by checking. See `docs/threat-intel-review-2026-07.md`.
- **Test the seams, not just the library.** `computeScores` shipped correct,
  tested, and called by nothing. Assert that a feature reaches a surface.
- **Fixtures lie.** The first const-eval fix passed every synthetic test and
  cleared 0 of 24 real findings, because the fixtures were all one-liners.
- **A probe must recognise the property, not one spelling.** Three probes
  rejected controls that were equal or stronger than the ones they suggested.
  That pushes authors toward weaker code.
- **"I cannot see it" is not "it is missing."** Where the value comes from an
  unresolvable call, decline rather than assert.
- **Never suppress a self-finding.** Fix the cause. The dogfood gate now runs
  all 100 probes over our own tree and fails on any critical or high.
