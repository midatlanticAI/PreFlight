## Things learned today worth keeping

- The canary replay found a defect the test suite could not: a whole-file masker bug only shows on real nested-template code. Keep replaying both corpora, with a baseline recorded before the first edit.
- In this harness, a Bash heredoc collapses `\\` to `\`. Any script carrying a regex goes through the Write tool, not a heredoc.
- `isTestFile` did not know `.test.mjs`. A Workers project writes every test that way. Check the file filter before the probe when a fixture-shaped file draws a finding.
- A finding count moving on a canary is not automatically wrong; it has to be explained line by line. Today's 22 gained were typed catches and Prettier-wrapped index keys becoming reachable; the 5 dropped were catches and state reads inside strings.
- Replay the canaries the same way every time. `GIT=1` scans tracked files; the walk mode skips files over 500KB, which hid `package-lock.json` on one corpus and made a lockfile finding look like a regression hours later. Record the mode with the baseline.
- The remaining 13 SQL Injection criticals on the field-scan target are identifier interpolation from code-owned lists (constant column arrays, allowlisted SET keys, `sqlite_master` table names). They are the manual-review class the probe exists to surface, not false positives; the fix on the target side is an identifier allowlist helper, not a probe change.
